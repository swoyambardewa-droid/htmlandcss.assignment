What I Learned

While completing this assignment, I learned how HTML and CSS work together to create a basic webpage.

One of the main things I practised was using different HTML elements to organize content. I also learned how class selectors make it possible to apply the same CSS rules to several elements.

I became more comfortable with CSS properties such as color, background-color, width, height, margin, padding, border and border-radius. I also used font and text properties to make the content easier to read.

Another useful part was learning about images. I used CSS to control the size of the course images and used object-fit so that the images would fit the card without being stretched.

I also learned how the :hover pseudo-class works. It is a small feature, but it makes links and buttons feel more interactive.

Finally, I practised arranging several cards without using Flexbox or CSS Grid. I used inline-block, which was useful because these layout methods have not yet been covered in the module.

Challenges and Solutions
Challenge 1: Getting the cards to appear beside each other

Initially, I had to think about how to place multiple cards on the page without using Flexbox or Grid.

Solution:
I used display: inline-block for the cards and adjusted their width and margins. This allowed the cards to appear beside each other while staying within the requirements of the assignment.

Challenge 2: Understanding margin and padding

I initially found it difficult to understand why changing padding and margin produced different spacing.

Solution:
I reviewed the CSS box model and experimented with the values in the browser. I learned that padding creates space inside an element, while margin creates space outside it.

Challenge 3: Making the images fit the cards

Some images did not have the same proportions, so they did not initially look consistent inside the cards.

Solution:
I gave the images a fixed width and height and used object-fit: cover. This made the images fit the same area while avoiding obvious stretching.
